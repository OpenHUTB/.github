配套社区LaTeX资源

本文参考文献编译操作，可以搭配OpenHUTB社区的LaTeX模板仓库使用： * 课程论文latex模板 * 本科毕设latex模板 * 硕士论文LaTeX模板

读者可以前往对应仓库获取完整LaTeX论文模板，本文仅讲解参考文献编译相关操作。

一、LaTeX 参考文献引用核心原理

LaTeX 的参考文献体系由 tex 主文件 + bib 文献库文件 协同工作，无法仅通过单次 PDF 编译生成正常参考文献。

核心文件作用：

  1. .bib：存放所有参考文献的作者、年份、标题、期刊等原始信息，是文献数据源。
  2. .aux：第一次编译自动生成，记录全文所有 \cite{} 引用标记与位置。
  3. .bbl：BibTeX 编译后自动生成，是最终排版好的参考文献正文，论文文末展示的文献全部来自该文件。

核心编译逻辑： PDFLaTeX 扫描引用记录 → BibTeX 生成规范文献列表 → 两次 PDF 编译刷新标号与格式。

二、标准完整编译顺序

所有课程论文、毕业论文、期刊通用四步标准流程，缺任意一步都会出现[?]、文献缺失、标号错乱。

  1. 第一次 PDFLaTeX 扫描全文引用命令，生成.aux辅助文件，记录所有被引用的文献 key，此时文末无参考文献。

  2. 执行 BibTeX 编译（最关键步骤） 读取.aux文件，匹配.bib文献库，自动生成标准化参考文献.bbl文件。

  3. 第二次 PDFLaTeX 将.bbl文献内容嵌入论文，页面出现参考文献列表，但引用标号可能未对齐、未刷新。

  4. 第三次 PDFLaTeX 全局刷新文中引用序号、超链接、排版格式，彻底消除问号、标号错位问题。

三、最简可直接运行模板

1. 主文件（.tex）核心代码

\documentclass{article}
\usepackage{cite}
\usepackage{hyperref}

\begin{document}

正文引用测试\cite{example1}。

style{plain}
{ref}

\end{document}

2. 文献库文件（ref.bib）示例

@article{example1,
  title={LaTeX文献引用技术研究},
  author={张三, 李四},
  journal={计算机工程与应用},
  year={2024}
}

四、常用参考文献格式样式

  1. plain：数字顺序编码，通用学术格式，本科论文常用。
  2. ieeetr：适配 IEEE 会议、英文期刊标准格式。
  3. gb7714-2015：中文毕业论文国标格式（首选）。
  4. apalike：作者-年份引用格式，适用于社科类论文。

中文论文国标配置专属代码：

\usepackage{gb7714-2015}
style{gb7714-2015}

五、常见报错原因与解决方案

1. 引用始终显示 [?]

  • 未执行 BibTeX 编译
  • 编译顺序缺失后续两次 PDF 刷新
  • 文中\cite标签与 bib 文件标签大小写、字符不一致（严格区分）

2. 提示未定义引用、文献找不到

  • {} 调用的 bib 文件名和实际文件不匹配
  • bib 文件存放路径错误（必须和 tex 主文件同目录）
  • bib 文件存在中文全角符号、空格、非法字符

3. 文献只显示部分内容

  • 未引用的文献默认不展示，需批量展示添加：\nocite{*}
  • 文献条目存在语法错误，BibTeX 自动跳过异常条目

4. 编译乱码、格式错乱

  • bib 文件编码非 UTF-8
  • 手动修改自动生成的.bbl文件（会被编译覆盖失效）

六、核心注意事项

  1. 禁止单次 PDF 编译 仅运行 PDFLaTeX 无法解析文献库，绝对无法生成完整参考文献。

  2. 严禁手动修改.bbl 文件 .bbl是系统自动生成文件，所有修改会被下一次编译覆盖，文献修改、增删只能在.bib文件中操作。

  3. 引用标签唯一不重复 整篇论文中，每一个文献 key 只能出现一次，重复会直接导致标号错乱、文献串位。

  4. 严格区分中英文符号 bib 文件内所有标点、括号、逗号必须是英文半角，中文符号是绝大多数编译报错的根源。

  5. 修改文献必须重跑完整四步 增删文献、修改文献信息、调整引用位置后，必须完整执行四轮编译，否则格式不更新。

  6. 异常报错万能修复法 出现标号错乱、文献丢失、莫名报错： 手动删除所有 .aux .bbl .blg .log 辅助文件，再完整执行四步编译，可解决 90% 问题。

  7. 区分中英文编译环境 英文论文用原生 plain/ieeetr 样式；中文毕业论文必须使用 gb7714-2015 宏包，符合国家标准排版。

七、极简总结

  1. 一次 PDF 扫引用 → BibTeX 生成文献 → 两次 PDF 刷新格式
  2. 所有文献数据只改 bib 文件，不动自动生成文件
  3. 符号统一英文、标签统一匹配、编译顺序不缺失
  4. 异常优先清理辅助文件重编译
