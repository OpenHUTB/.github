Markdown 一键发到微信/知乎/小红书/Twitter

  • 安装 Markdown2Anything 插件

  • 打开任意 .md 文件，右键 → Markdown2Anything: 预览

  • 工具栏按钮选择目标操作

微信

  • 点击上面工具栏中的“微信”->“上传到草稿箱”

  • 从微信公众号的“设置与开发”->“账号设置”->“注册信息”中找到“AppID”

  • 从微信公众号的“设置与开发”->“开发接口管理”->“微信开发者平台”->“我的业务与服务”->“公众号”->开发密钥->启用“AppSecret”
