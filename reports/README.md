# reports 文件夹说明

本目录存放 OpenHUTB 项目自动化统计生成的数据报告，主要为 CSV 格式。

## 自动生成的报告
这些报告由 GitHub Actions 工作流（`repo_metrics_action`）每月自动生成，文件命名包含时间戳（如 `OpenHUTB-2026-10-01T03-13-222-30-days.csv`），用于追溯项目活跃度或提交记录。

如果需要查看历史报告，直接在本目录中查找对应的 CSV 文件即可。报告缺失时，需等待下月自动生成，或在 Actions 页面手动触发工作流。

## 手动统计工具
除了自动生成的报告外，项目还提供了一个手动统计脚本 `src/git_commit_stats.py`，用于统计指定时间段内的提交记录。该脚本需要手动运行，不会自动生成报告，也不会影响本目录下的自动报告文件。

### 使用方法
1. 确保本地已安装 Python 环境。
2. 切换到项目根目录，打开命令行终端。
3. 运行以下命令，例如统计特定时间段的提交：
   ```bash
   python src/git_commit_stats.py --since "2026-02-27 18:00" --until "2026-03-08 00:00" --output commit_stats.csv
