OpenHUTB 社区

欢迎使用开源孪创（Open source Humanoid-vehicle Twin Build, OpenHUTB）的社区简介，该社区提供一款加速人和载具代理开发的影视级模拟器，其中人包括人形机器人（Humanoid）和仿生人（Android），载具包括地面载具、空域载具、水域载具，社区本身采用分布式架构。

3. 问题

  • 如果参与过程中遇到任何问题，请参考 提问技巧 和 注意事项 或在对应项目的 Issues页面 提出问题。

4. 社区

  • 用户的社区参与度月度统计情况 - 该 action 页面的 User Activity Report 里，每月1号自动进行统计，注意，该量化统计情况仅作参考，不代表代码质量的优劣

  • 宣传

OpenHUTB 的其他非主要平台包括 gitee、gitcode、gitlink、红山开源、阿里云、atomgit、腾讯工蜂，社交平台包括：
微信公众号 微信 知乎 B 站
小红书 Twitter(X) Youtube 赞助

备注：开源孪创社区不搭建自己独立的平台的原因有很多，比如独立平台生成的“信息孤岛”造成分裂、维护成本高、“去中心化”理念与降低用户门槛、风险规避与可持续性，同时不会因为其中一些依附平台的限制而影响社区的发展，使社区专注于核心使命。

如果对文档中的任何问题可以在 本文档的源码仓库 中的 问题 页面讨论或者提交 拉取请求 直接修改文档。
