开源工具列表

这里展示和 OpenHUTB 相关的开源项目。

入选标准（非硬性）：最近一年在有提交修改、星星数大于100。

工具

  • ScreenToGif - 截图为gif动图

  • shotcut - 视频编辑

  • vlc - 视频播放

  • obs-studio - 直播、屏幕录制。

  • sumatrapdf - PDF 阅读器

  • Okular - 可以查看和注释各种格式的文档，包括 PDF、Postscript、漫画书以及多种图像格式。它支持原生 PDF 注释功能。

  • One-click-cleaning-of-C-drive - 清理C盘残留和垃圾

  • WindowsCleaner - C盘清理

办公

  • rustdesk - 远程桌面应用程序，专为自托管设计，作为 TeamViewer 的替代方案。

  • tailscale - 使用 WireGuard 和双重身份验证最简单、最安全的方式

  • LibreOffice - Office 办公软件

  • virtualbox - 虚拟机

  • md2wechat-skill - 一键排版发布到微信公众号

  • pywechat - windows桌面微信自动化

开发

  • TortoiseGit - Windows 资源管理器扩展用于操作 Git

  • auto-py-to-exe - pthon 转可执行 exe 的图形界面

其他

  • openvpn - VPN 代理

  • krita - 从零开始创建数字艺术文件的端到端解决方案

  • DocumentServer - 在线协作办公

  • Mailspring - 邮箱客户端

  • scrcpy - 显示并控制安卓设备

  • HivisionIDPhotos - AI证件照制作算法

  • readest - 电子书阅读器

  • openreel-video - 浏览器视频编辑器

  • ssr - Linux 上的屏幕录制

  • PDF4QT - PDF编辑器

  • Stirling-PDF - PDF 应用程序，可让您在任何设备和任何地方编辑 PDF 文件

  • pdfsam - 分割、合并、混合、旋转 PDF 文件以及提取页面

  • gimp - 图像处理

  • GIMP-ML - GNU图像处理程序的AI

  • rembg - 去除图片背景的工具

  • Motrix - 下载管理器，可处理 HTTP、FTP、BitTorrent 和磁力链接（Magnet）等多种下载任务

  • FileCentipede - 网络上传/下载管理器

  • FileConverter - 可通过Windows资源管理器的上下文菜单来转换和压缩文件

  • windows - Docker 容器中的 Windows

  • SpaceSniffer - Windows 的免费磁盘空间分析工具，它采用分层地图（Treemap）的概念来显示当前的磁盘使用情况。

  • FreeCAD - 3D参数化建模器

  • SeleniumBase - 用于网页自动化、测试及绕过机器人检测的API

  • selenium - 浏览器自动化框架

研究

  • LaTeX-OCR - 将方程图像转换为 LaTeX 代码

  • arxiv-latex-cleaner - 轻松清理论文的 LaTeX 代码，以便提交至 arXiv

  • PDFMathTranslate - 基于 AI 完整保留排版的 PDF 文档全文双语翻译

常见

  • Chromium - Chromium 浏览器

  • vscode - 代码编辑

  • WSL - Windows 平台的 Linux 子系统

  • texstudio - LaTeX 编辑器
