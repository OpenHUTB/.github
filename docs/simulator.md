# OpenHUTB 模拟器简介

## OpenHUTB 的工作原理

[**OpenHUTB**](https://github.com/OpenHUTB/hutb) 采用模块化架构，因此非常适合构建覆盖多种机体形态的机器人策略，包括人形机器人、肌肉骨骼人、地面载具、空域载具和水域载具。

同时，它提供了一套完整的机器人学习框架，涵盖从环境搭建到策略训练的全流程，并支持模仿学习与强化学习两类方法。此外，还可以集成 NVIDIA® PhysX®、MuJoCo、Chrono 等多种物理引擎，进一步定制和扩展 OpenHUTB 的能力。
