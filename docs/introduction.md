## 涉水效果

* 流固耦合

![type:video](./img/117%20Fording%20Simulation%20Constraint%20Fluids.mp4)
视频内容阐述
 
该视频展示涉水仿真模拟，采用流固耦合方法，模拟固体结构和水流之间的相互作用：水流冲击固体构件，结构会受水压力产生形变；同时固体的姿态、位移反过来改变水流场分布，是双向耦合计算。视频里设置了对应的约束边界条件，复现物体涉水行进时流体与结构的动态交互过程。
 
要点
 
1. 仿真类型：涉水效果模拟，核心方法为流固耦合
2. 核心原理：流体与固体相互影响（双向作用）
3. 仿真设置：添加约束条件，完成涉水工况计算
4. 作用：观察水流冲击、结构受力变形的动态结果
