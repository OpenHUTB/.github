# Java版MC回到旧版本指南

一觉醒来发现 PCL2 悄悄更新，下载功能直接失效了，别着急，跟着这份教程操作，就还能像以前一样正常游玩 MC。
> 背景：2026-10-20 发布的 2.99.0.0 版本起，PCL2 移除了《我的世界》本体在线下载功能，作者给出的理由是"遵守相关法律法规"。
>
> 不影响是：已安装的游戏、存档、Mod、版本隔离、账号、联机、皮肤都能够使用。需要解决的只是两件事，第一还没更新的怎么锁住旧版本，以及已经更新的怎么退回去。

---

## 一、假如你还没有更新

1. **关闭自动更新**
   首先在打开PCL2启动器之前，你需要断开网络连接。断开网络后 -> 打开 PCL2 -> 设置 -> 关闭"自动更新 / 启动时检查更新"。之后如果弹出"发现新版本"，直接关闭窗口重进，不要点更新。
2. **趁下载通道还在，可以先把需要的版本装好**
   近期想玩的游戏版本、Forge / Fabric、整合包，一次性下载安装好。
3. **本地备份一份旧版 exe**
   按方案 B 的第 1 步把旧版安装包下载保存好。万一被升级，直接覆盖回来即可。

---

## 二、若已经更新，则需要回退到旧版

**操作步骤如下：**

**第 1 步：下载官方旧版安装包**

国内直连 raw.githubusercontent.com 经常失败，使用镜像地址（浏览器直接打开）：

```
https://gh-proxy.com/https://raw.githubusercontent.com/Meloong-Git/PCL/2.14.0.0/最新正式版.zip
```

得到一个约 2.57 MB 的 zip，里面只有一个文件：`Plain Craft Launcher 2.exe`。
如果镜像失效，把开头的 `gh-proxy.com` 依次换成 `githubfast.com`、`gh.llkk.cc` 重新尝试。

**第 2 步：核对文件，确认没被替换过**

解压出 exe 后，在其所在文件夹打开 PowerShell 运行：

```powershell
(Get-Item ".\Plain Craft Launcher 2.exe").VersionInfo.FileVersion
Get-FileHash ".\Plain Craft Launcher 2.exe" -Algorithm SHA256
```

- 版本号应为 **2.13.1.1**
- SHA256 应为 `30EB93C62FC51EDE0898648E67455478A3D5A4F279938AE65AEC77B84CB9703F`

两项对不上，说明文件被改动或下错了，删除后重新下载。

**第 3 步：替换主程序**

完全退出 PCL2（任务管理器确认进程已关闭），把核对过的旧 exe 复制到 PCL2 所在文件夹，选择替换。
存档、Mod、版本隔离都在同目录的 `.minecraft` 文件夹中，替换 exe 不会影响这些内容。

**第 4 步：断网启动，关闭更新，再联网**

先断网启动一次旧版，进入设置关闭自动更新，然后再联网。这样可以避免启动器联网时自动升级回 2.99。

**第 5 步：确认恢复正常**

打开左侧"下载"页，能看到版本列表、能安装 Forge / Fabric、能导入整合包，即表示回退成功。

---

## 安全提醒

- 不要使用网盘、群文件、评论区流传的"修复版 / 魔改版 / 一键恢复补丁"，这类文件无法确认是否被改动过。
- 网络上有 PCL Helper、图灵镜之类的工具，作用是给新版 exe 打补丁来恢复下载。它虽然开源，但程序未签名，且 PCL 每次更新后都可能失效，风险比直接回退旧版更高，需要自行判断。
- 回退旧版是在官方停止提供下载功能之后的个人使用选择，请知悉这一背景。
