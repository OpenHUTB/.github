!!! 笔记

    * 为了便于手机端阅读，正文字体大小设置为 17，小标题字体大小设置为 18。
    
    * 风格选“微信经典”。

    * 图片前不要用空行


需要检查的格式内容包括：

* 图片前后是否有多余的空行
* 图注是否正常显示或重复显示
* 如果公式格式混乱，改用截图
* 出现超过 5M 的 gif 动图一般会上传失败的现象，请使用 ScreenToGif “编辑-> 减少帧数”、“图像 -> 调整大小” 来压缩
* Python 代码的 class、def、return 等关键字后面是否出现：缺少空格、代码未正确对齐的情况

需要检查的内容：

* 文章需要包括一定图像和动图，不能全部是文字；
* 必要的公式、核心代码、原理的说明；
* 选填内容：在文章最后填写编辑和审核（如有）
* 必填发表选项：作者（OpenHUTB 或 github 用户名或真实姓名）、封面（最具代表性和吸引力）、摘要、原创声明（默认）、原文链接（一般为参考的文档在线地址）
* 选填发表选项：合集
* 文字、图片等内容不能有任何 AI 的风格和痕迹

确认检查完成后，选中除了第一行标题外的所有内容，复制到微信公众号的草稿的正文部分。

发表过程：

* 定时发表：设置为离编辑完成最近的有群发通知的某一天发表，时间段选择 7:50-8:50、11:50-12:50、18:00-19:00、21:00-22:00 中的随机时刻。
* 将预览链接等效果<a href="mailto:open@hutb.edu.cn">发送到邮箱 open@hutb.edu.cn</a>进行**审核发表**，不直接发表，否则解除运营者权限。


### 自定义样式

在预览页面点击“更多 -> 设置 -> 打开自定义样式面板”，拖到最下面的“CSS 编辑器”，输入以下内容（这里以调整标题的字体大小为例）：

```css
.article-wrapper h2 {
    font-size: 19px;
}
.article-wrapper h3 {
    font-size: 18px;
}
.article-wrapper h4 {
    font-size: 17px;
}
```

注意：正文默认字体大小 16。
```css
.article-wrapper p {
    font-size: 18px;
}
```

点击“应用”，即可在预览窗口看到改变后的字体大小。

## 发布检查流程

```mermaid
flowchart LR
    A[整理 Markdown 正文] --> B[在插件中预览]
    B --> C[检查图片与公式]
    C --> D[切换目标平台样式]
    D --> E[检查手机端排版]
    E --> F[发布或保存草稿]
    F --> G[打开成品回查]
```

### 预览时

- 检查标题层级、代码块、表格和引用是否完整。
- - 确认图片能够显示，图注没有重复，动图大小符合平台限制。
  - - 公式显示异常时，先在目标平台预览，再决定是否改为清晰图片。
   
    - ### 发布前后
   
    - 发布前切换到目标平台样式，重点查看手机端的换行、图片宽度和段落间距。发布或保存草稿后，再打开成品页面检查目录跳转、图片清晰度和外部链接。
