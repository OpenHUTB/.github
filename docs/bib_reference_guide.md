## 一、LaTeX 参考文献引用核心原理
LaTeX 的参考文献体系由 tex 主文件 + bib 文献库文件 协同工作，无法仅通过单次 PDF 编译生成正常参考文献。

核心文件作用：

1. `.bib`：存放所有参考文献的作者、年份、标题、期刊等原始信息，是文献数据源。
2. `.aux`：第一次编译自动生成，记录全文所有 `\cite{}` 引用标记与位置。
3. `.bbl`：BibTeX 编译后自动生成，是最终排版好的参考文献正文，论文文末展示的文献全部来自该文件。

核心编译逻辑：
PDFLaTeX 扫描引用记录 → BibTeX 生成规范文献列表 → 两次 PDF 编译刷新标号与格式。

## 二、标准完整编译顺序
所有课程论文、毕业论文、期刊通用四步标准流程，缺任意一步都会出现`[?]`、文献缺失、标号错乱。

1. **第一次 PDFLaTeX**
扫描全文引用命令，生成`.aux`辅助文件，记录所有被引用的文献 key，此时文末无参考文献。

2. **执行 BibTeX 编译（最关键步骤）**
读取`.aux`文件，匹配`.bib`文献库，自动生成标准化参考文献`.bbl`文件。

3. **第二次 PDFLaTeX**
将`.bbl`文献内容嵌入论文，页面出现参考文献列表，但引用标号可能未对齐、未刷新。

4. **第三次 PDFLaTeX**
全局刷新文中引用序号、超链接、排版格式，彻底消除问号、标号错位问题。

## 三、最简可直接运行模板

### 1. 主文件（.tex）核心代码

```latex
\documentclass{article}
\usepackage{cite}
\usepackage{hyperref}

\begin{document}

正文引用测试\cite{example1}。

\bibliographystyle{plain}
\bibliography{ref}

\end{document}
```

### 2. 文献库文件（ref.bib）示例

```bibtex
@article{example1,
  title={LaTeX文献引用技术研究},
  author={张三 and 李四},
  journal={计算机工程与应用},
  year={2024}
}
```

## 四、常用参考文献格式样式

1. `plain`：以数字标注引用，文献列表通常按作者等信息排序，不按正文中首次引用的先后排列。
2. `ieeetr`：按正文引用顺序排列的数字样式；投稿时仍需使用期刊或会议指定的模板。
3. `gbt7714-numeric`：`gbt7714` 提供的 GB/T 7714—2015 顺序编码样式；著者—出版年制对应 `gbt7714-author-year`。
4. `apalike`：作者-年份引用格式，适用于社科类论文。

使用 BibTeX 的模板可按下例配置国标顺序编码样式：

```latex
\usepackage{gbt7714}
\bibliographystyle{gbt7714-numeric}
```

宏包名是 `gbt7714`，不是 `gb7714-2015`；需先在 TeX 发行版中安装该宏包。它与 `natbib` 配合使用，不要再叠加本页最简示例中的 `cite` 宏包。已有模板若已加载引用宏包或设置文献样式，先检查模板说明，避免重复配置。

本例适用于 BibTeX，文献库仍通过 `\bibliography{ref}` 载入。采用 `biblatex` 和 Biber 的模板使用另一套配置，不能直接套用这里的宏包和编译顺序。参见 [gbt7714 使用说明](https://github.com/zepinglee/gbt7714-bibtex-style#usage)。


## 五、常见报错原因与解决方案

### 1. 引用始终显示 `[?]`

- 未执行 BibTeX 编译
- 编译顺序缺失后续两次 PDF 刷新
- 文中`\cite`标签与 bib 文件标签大小写、字符不一致（严格区分）

### 2. 提示未定义引用、文献找不到

- `\bibliography{}` 调用的 bib 文件名和实际文件不匹配
- bib 文件存放路径错误（默认放在 tex 主文件同目录；放在子目录时需写成 \bibliography{refs/ref} 这样的相对路径）
- bib 文件存在中文全角符号、空格、非法字符

### 3. 文献只显示部分内容

- 未引用的文献默认不展示，需批量展示添加：`\nocite{*}`
- 文献条目存在语法错误，BibTeX 自动跳过异常条目

### 4. 编译乱码、格式错乱

- bib 文件编码非 UTF-8
- 手动修改自动生成的`.bbl`文件（会被编译覆盖失效）

## 六、核心注意事项

1. **禁止单次 PDF 编译**
仅运行 PDFLaTeX 无法解析文献库，绝对无法生成完整参考文献。

2. **严禁手动修改`.bbl` 文件**
`.bbl`是系统自动生成文件，所有修改会被下一次编译覆盖，文献修改、增删只能在`.bib`文件中操作。

3. **文献条目的 key 需要唯一**
同一个 `.bib` 文件中，不同文献条目不能使用相同的 key，否则 BibTeX 无法准确区分条目。同一个 key 可以在正文的多处 `\cite{}` 中重复使用，这些位置会指向同一条参考文献。

4. **严格区分中英文符号**
bib 文件内所有标点、括号、逗号必须是英文半角，中文符号是绝大多数编译报错的根源。

5. **修改文献必须重跑完整四步**
增删文献、修改文献信息、调整引用位置后，必须完整执行四轮编译，否则格式不更新。

6. **重新生成辅助文件**
修改引用后仍出现旧编号或旧内容时，可以先查看 `.blg` 和 `.log` 中的报错。确认 `.bib` 语法、文件名和 key 都正确后，再删除 `.aux`、`.bbl`、`.blg`、`.log` 等辅助文件，并按完整顺序重新编译。清理辅助文件适合解决缓存的旧结果，不能替代对原始错误的检查。

7. **区分中英文编译环境**
先按学校、期刊或会议的模板选择样式。使用 BibTeX 且要求 GB/T 7714—2015 时，可按第四节配置 `gbt7714`；模板已有设置时不重复加载。

## 七、极简总结

1. 一次 PDF 扫引用 →  BibTeX 生成文献 → 两次 PDF 刷新格式
2. 所有文献数据只改 bib 文件，不动自动生成文件
3. 符号统一英文、key 唯一并与引用匹配、编译顺序不缺失
4. 异常先查看日志并修正原始问题，必要时清理辅助文件后重编译
