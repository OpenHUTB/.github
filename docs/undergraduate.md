# 本科毕业设计

## 写作总体要求

开发系统写法上必须列出**实现的功能**，而不是有什么写什么。论文必须包括以下五个部分：

1. 需求分析
2. 系统设计
3. 编码和实现
4. 系统测试
5. 系统部署和维护

其他要点：

- 数据库：需要包含数据库设计
- 测试：单元测试、集成测试、功能测试、性能测试、压力测试

## 算法类要求（做算法的）

- 必须对现有算法有**改进和对比**，而不是仅仅跑通现有算法（比如仅仅跑 DeepSORT）
- 常用做法：加入注意力机制进行改进，有性能的提升
- 论文必须包含：
  1. 基准方法和自己改进算法的描述，比如加入注意力机制（第三章）
  2. 自己的方法必须比现有方法好一些（第四章）

### 对比结果的记录方式

报告改进效果时，可同时说明以下信息，便于读者判断差异是否来自算法本身：

- 基准方法和改进方法使用相同的数据集、数据划分及预处理方式。
- 说明评价指标及其含义；例如准确率越高越好，运行时间越短越好。
- 记录硬件、软件版本和主要运行参数；含随机过程的实验可重复运行并报告平均结果。
- 除总体结果外，列出效果没有提升或出现退化的场景，并说明可能原因。
